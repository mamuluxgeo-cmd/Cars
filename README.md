# 🚗 მძღოლების სამართავი სისტემა

მობილურზე ოპტიმიზებული პლატფორმა — მძღოლები რეგისტრირდებიან, ირჩევენ მანქანას, აფიქსირებენ სვლის დაწყება/დასრულებას და საწვავის ლიტრაჟს. ადმინ პანელში ჩანს სრული სტატისტიკა.

**არქიტექტურა:** Frontend (HTML+JS) → GitHub Pages-ზე • Backend (Apps Script) → Google Sheets ბაზა.

## 🛠️ Setup — 5 ნაბიჯი

### 1) Google Sheet-ის შექმნა
1. გახსენი https://sheets.google.com → **Blank**
2. დაარქვი `Drivers Manager` (ან რაც გინდა)
3. URL-დან დააკოპირე **Spreadsheet ID** — ეს ნაწილი:
   ```
   https://docs.google.com/spreadsheets/d/SPREADSHEET_ID_HERE/edit
   ```

### 2) Apps Script-ის ატვირთვა
1. იმავე Sheet-ში: **Extensions → Apps Script**
2. წაშალე `Code.gs`-ის ნაგულისხმევი შიგთავსი
3. ჩასვი ჩვენი `Code.gs`-ის სრული შიგთავსი
4. ზედა ნაწილში შეცვალე:
   ```js
   const SPREADSHEET_ID = 'შენი_ID_აქ';
   const ADMIN_PIN = '1234';   // შეცვალე საკუთარი PIN-ით
   ```
5. Save (💾) → ფუნქციების სიიდან აირჩიე `initSheets` → **Run**
   - პირველად მოგთხოვს authorize → დაეთანხმე
   - Sheet-ში გამოჩნდება 4 ფურცელი (Drivers, Cars, Sessions, Fuel) მაგალითი მონაცემებით

### 3) Web App-ად გამოქვეყნება
1. Apps Script ფანჯარაში: **Deploy → New deployment**
2. ⚙️ → **Web app**
3. **Execute as:** Me · **Who has access:** Anyone
4. Deploy → დააკოპირე **Web app URL** (`/exec`-ით ბოლოვდება)
5. ⚠️ ყოველ ცვლილებაზე **New deployment** ან **Manage deployments → Edit → New version**

### 4) Frontend-ის კონფიგი
`config.js`-ში:
```js
window.API_URL = "https://script.google.com/macros/s/.../exec";
```

### 5) GitHub Pages-ზე ატვირთვა
1. GitHub-ზე ახალი repo (Public)
2. ატვირთე ეს 5 ფაილი (`index.html`, `admin.html`, `style.css`, `config.js`, `README.md`)
3. **Settings → Pages → Branch: main / root → Save**
4. 1 წუთში გექნება ლინკი: `https://username.github.io/repo-name/`
5. ტელეფონში გახსენი → Safari/Chrome-ში: **Add to Home Screen** — გამოიყურება როგორც აპი

## 👤 გამოყენება

### მძღოლი
1. ხსნის ლინკს ტელეფონში
2. შედის იუზერითა და PIN-ით
3. **სვლის დაწყება** → ირჩევს მანქანას
4. სვლის დასრულებისას → **სვლის დასრულება**

### ადმინი (შენ)
1. `/admin.html` ლინკზე → შედი ADMIN_PIN-ით
2. **მთავარი** — ვინ ახლა ამოძრავებს, ვის რამდენი საათი აქვს
3. **სესიები** — სრული ისტორია (ავტომატურად დახურული მონიშნულია 🟡 ტეგით)
4. **საწვავი** — ჩასხმების ლოგი მანქანების მიხედვით
5. **მძღოლები / მანქანები** — დამატება/წაშლა

## ⚙️ Tech notes

- **CORS:** Apps Script Web App-ი default-ით ნებას რთავს cross-origin POST-ს როცა `Content-Type: text/plain`-ია (ამიტომაც ვიყენებთ ამას frontend-ში)
- **Auth:** მძღოლის token = base64(`id:pin`). Sheets-ში PIN ღია ტექსტითაა — ეს არ არის bank-grade სისტემა, მაგრამ შიდა გუნდისთვის მისაღებია. თუ უსაფრთხოება საჭიროა, PIN-ს Apps Script-ში hash-ი დაუდე.
- **Quota:** Apps Script Web App ნებადართულია ~20,000 ჯერ დღეში free account-ზე — საკმარისია მცირე-საშუალო ფლოტისთვის.
